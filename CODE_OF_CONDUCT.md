# Code of Conduct

## Purpose
Our community aims to provide a welcoming, collaborative, and harassment-free environment for everyone who engages with the Telegram Media Downloader project, regardless of experience level, identity, or background.

## Expected Behavior
- Show empathy and respect toward other community members.
- Offer constructive feedback, especially when reviewing code or documentation.
- Assume good intent, yet address problems promptly and directly.
- Share knowledge generously and attribute the work of others when you build upon it.
- Follow the guidelines documented in this repository, including security and contribution requirements.

## Unacceptable Behavior
- Harassment, discrimination, or offensive comments related to personal attributes or beliefs.
- Intimidation, deliberate intimidation, or stalking in any community space.
- Posting or threatening to post identifying information without explicit consent.
- Disruptive behavior that derails discussions or prevents constructive collaboration.
- Any conduct that violates applicable laws or third-party terms of service.

## Scope
This Code of Conduct applies to all project spaces, including GitHub repositories, issue trackers, documentation sites, chat channels, and any private communication initiated through project resources. It also applies when individuals are officially representing the project in public spaces.

## Reporting
If you experience or witness behavior that violates this Code of Conduct, please report it as soon as possible by:
- Opening a GitHub issue with the "Code of Conduct" label (or equivalent) containing as much context as you can safely share.
- Alternatively, contacting the project maintainers via the communication channels listed in the repository documentation.

Maintain confidentiality for those involved, and avoid public accusations before the maintainers have an opportunity to evaluate the situation.

## Enforcement
- The project maintainers are responsible for clarifying and enforcing this Code of Conduct.
- Reports will be reviewed promptly and kept to the minimum group of maintainers necessary to address the situation.
- When a violation is confirmed, the maintainers may take any action deemed appropriate, including warnings, temporary bans, or permanent removal from project spaces.

## Commitment to Improvement
Maintainers will periodically revisit this Code of Conduct to ensure it reflects the community's needs and industry best practices. Suggestions for refinements are welcome via pull requests or discussions.
